# HumanOrBot bot

FastAPI bot for the HumanOrBot project. `/get_message` answers with a real LLM
reply; `/predict` keeps the message classifier endpoint.

## Session 9 — run everything with Docker Compose

Three services (`docker-compose.yaml`):

| service | what | port |
|---|---|---|
| `llm` | `llama.cpp` server (OpenAI-compatible), Qwen2.5-0.5B-Instruct GGUF | 8080 |
| `fastapi` | bot backend — `/get_message` forwards the prompt to `llm` and returns the reply | 6872 |
| `streamlit` | chat UI | 8501 |

```bash
docker compose up --build
```

Then open the chat at **http://localhost:8501** — replies are generated by the LLM
(not echoed). On first start the `llm` service downloads the GGUF from Hugging Face
(cached in the `llm-models` volume); `fastapi` waits for it via a healthcheck.

Quick checks:

```bash
curl http://localhost:8080/v1/models                       # model is loaded
curl -X POST http://localhost:6872/get_message \
  -H 'content-type: application/json' \
  -d '{"dialog_id":"0f2d4682-d939-4af6-beb9-880a5da202a2",
       "last_msg_text":"hi, how are you?",
       "last_message_id":"13ab658b-8463-4410-a747-33ea2dfb7b68"}'
```

Config via env (see `.env.example`): `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`,
`LLM_MAX_TOKENS`, `LLM_TEMPERATURE`, `ECHO_BOT_URL`.

> The Docker image is lean (no torch/transformers), so the bot starts fast. `/predict`
> returns a neutral `0.5` there; the real zero-shot classifier (`MishaZeroshot`) runs as
> its own service from the previous task.

## Overview (legacy echo bot)

The original template echoed messages back; the legacy `run_all_linux.sh` (poetry +
SSH tunnel + streamlit) is kept below.

## Running the Service

Go to the project directory:

### On Linux/macOS

```bash
chmod +x run_all_linux.sh
```

```bash
./run_all_linux.sh
```

### On Windows

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\run_all_windows.ps1
```

#### These scripts will:
1. Install Poetry (if needed)
2. Install project dependencies
3. Set up an SSH tunnel to the remote host
4. Start the FastAPI application on port 6782
